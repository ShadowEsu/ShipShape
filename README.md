# ShipShape

Paste your GitHub repo, get a launch report in minutes: what will get your app rejected, which laws apply, and which documents you are missing, written to match what your code actually does.

Every finding points to a line of code and the rule it touches. ShipShape states facts about the code and cites the rule; it is not legal advice.

Status: planning. The first version gets built at Cal Hacks 13.0 (Oct 23 to 25, 2026).
